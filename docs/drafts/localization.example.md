# 2.3 Localization

The site is configured for English-only publication with localization
scaffolding already enabled through `mkdocs-static-i18n`.

## Current policy

- English is the default and only active language.
- Source pages use normal paths such as `index.md` and
  `chapters/3-architecture/protocol.md`.
- Future translated pages should use the suffix structure, such as
  `index.it.md` or `chapters/3-architecture/protocol.it.md`.

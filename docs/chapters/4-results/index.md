# 4. Results

This chapter separates verification evidence from physical implementation
results. Verilator/Cocotb can establish functional behavior and cycle counts;
it cannot establish FPGA utilization or 250 MHz timing closure.

Current reproducible evidence is summarized in [Verification](verification.md).
Vivado utilization, routed timing, power, and hardware link measurements must
be added only from preserved tool reports for the selected device/profile.

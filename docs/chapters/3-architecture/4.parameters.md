# 3.4 PRISM Parameters

PRISM separates three kinds of configuration:

1. **Protocol constants** define the wire ABI and cannot change within Protocol
   1.0.
2. **Elaboration parameters** select synthesized capacity and compiled features.
3. **Runtime operation state** selects topology, formats, accumulator profile,
   policy, routes, windows, and retry behavior within compiled limits.

The project-wide defaults and derived functions live in
`repo/rtl/src/prism_pkg.sv`; modules refer to those values rather than repeating
literals. A module may expose a package value as a parameter default:

```systemverilog
parameter int unsigned DATA_W = prism_pkg::PRISM_AXIS_DATA_W;
```

Changing an elaboration parameter creates a new bitstream and therefore a new
capability response. Runtime values arrive through validated CONTROL setup and
do not require resynthesis.

## Protocol 1.0 constants

These names belong in `prism_pkg.sv` for one-source consistency, but editing
them is a protocol change rather than ordinary configuration.

```systemverilog
// Wire-version negotiation.
localparam int unsigned PRISM_VERSION_MAJOR = 1;
localparam int unsigned PRISM_VERSION_MINOR = 0;

// Experimental Layer-2 discriminator.
localparam logic [15:0] PRISM_ETHERTYPE = 16'h88B5;

// Ethernet payload bytes available to PRISM.
localparam int unsigned PRISM_ETH_MTU_BYTES = 1500;

// Version/opcode word at the start of the Ethernet payload.
localparam int unsigned PRISM_CONTROL_WORD_BYTES = 2;

// Fixed class headers following the control word.
localparam int unsigned PRISM_DATA_HEADER_BYTES     = 24;
localparam int unsigned PRISM_RESULT_HEADER_BYTES   = 24;
localparam int unsigned PRISM_CONTROL_HEADER_BYTES  = 24;
localparam int unsigned PRISM_PROGRESS_HEADER_BYTES = 40;

// Numeric bytes in one DATA/RES chunk: 1500 - 2 - 24 = 1474.
localparam int unsigned PRISM_CHUNK_PAYLOAD_BYTES =
    PRISM_ETH_MTU_BYTES -
    PRISM_CONTROL_WORD_BYTES -
    PRISM_DATA_HEADER_BYTES;
```

`elements_per_chunk(format)`, `chunk_count(Element Count, format)`, First
Element, last-packet elements, and backend lane counts are package **functions
or local parameters**, not public knobs. This prevents illegal combinations.

## Platform and deployment capacity

```systemverilog
// OpenNIC packet datapath width.
parameter int unsigned PRISM_AXIS_DATA_W = 512;

// Packet clock for two 100 Gbit/s ports.
parameter int unsigned PRISM_DATAPATH_CLK_HZ = 322_265_625;

// Shell configuration clock.
parameter int unsigned PRISM_CFG_CLK_HZ = 125_000_000;

// Independent full-duplex physical ports.
parameter int unsigned PRISM_NUM_PORTS = 2;

// Internal VOQ rows: collective/result, management, and reliability.
parameter int unsigned PRISM_NUM_INTERNAL_SOURCES = 3;

// Ethernet frame bytes without FCS.
parameter int unsigned PRISM_MAX_FRAME_BYTES = 1514;

// SINGLE: two attached ranks, local aggregation, and local result delivery.
parameter logic [7:0] PRISM_NODE_ROLE_DEFAULT = 8'h04;

// Default dense Contributor IDs; protocol width remains 16 bits.
parameter int unsigned PRISM_NUM_LOCAL_CONTRIBUTORS = 2;

// Default two-rank ALLREDUCE fan-out.
parameter int unsigned PRISM_MAX_RESULT_ROUTES = 2;
```

Local MACs, Contributor bindings, node role, parent action, result routes, and
Result Path IDs remain runtime state.

## Compiled protocol and arithmetic support

```systemverilog
// REDUCE (0x01) and ALLREDUCE (0x02): both V1 semantics are executable.
parameter logic [63:0] PRISM_COLLECTIVE_SEMANTIC_MASK =
    (64'b1 << 8'h01) |
    (64'b1 << 8'h02);

// SUM (0x01): element-wise sum is the V1 backend operation.
parameter logic [63:0] PRISM_REDUCTION_OPERATOR_MASK =
    (64'b1 << 8'h01);

// FP16 (0x02), BF16 (0x03), and FP32 (0x04) endpoint DATA formats.
parameter logic [63:0] PRISM_INPUT_FORMAT_MASK =
    (64'b1 << 8'h02) |
    (64'b1 << 8'h03) |
    (64'b1 << 8'h04);

// FP32 (0x04) is the only V1 switch-to-switch partial DATA format.
parameter logic [63:0] PRISM_PARTIAL_FORMAT_MASK =
    (64'b1 << 8'h04);

// FP16 (0x02), BF16 (0x03), and FP32 (0x04) RES formats.
parameter logic [63:0] PRISM_OUTPUT_FORMAT_MASK =
    (64'b1 << 8'h02) |
    (64'b1 << 8'h03) |
    (64'b1 << 8'h04);

// FP32 (0x01) accumulator representation.
parameter logic [63:0] PRISM_ACCUM_PROFILE_MASK =
    (64'b1 << 8'h01);

// EAGER (0x01) or deterministic CONTRIBUTOR_ORDERED (0x02) local folding.
parameter logic [63:0] PRISM_ACCUM_POLICY_MASK =
    (64'b1 << 8'h01) |
    (64'b1 << 8'h02);

// Protocol 1.0 setup, discovery, resources, status, and lifecycle.
parameter bit PRISM_ENABLE_INBAND_CONTROL = 1'b1;

// PROGRESS, duplicate handling, acknowledgment, replay, and retry.
parameter bit PRISM_ENABLE_HOP_RELIABILITY = 1'b1;

// Window bitmaps and independent result-path completion.
parameter bit PRISM_ENABLE_SELECTIVE_ACK = 1'b1;
parameter bit PRISM_ENABLE_RESULT_ACK    = 1'b1;

// Session ownership expiry and cleanup.
parameter bit PRISM_ENABLE_LEASED_SESSIONS = 1'b1;

// LAB_UNAUTHENTICATED (0x00): initial laboratory management profile.
parameter logic [63:0] PRISM_SECURITY_PROFILE_MASK =
    (64'b1 << 8'h00);
```

The supported arithmetic capability is generated as five-field tuples:
`(input, accumulator profile, accumulation policy, partial, output)`. Masks are
only registry filters; the implementation advertises a tuple only when all
required converters, backend, finalizer, and wire paths are present.

Accumulator width is a backend property. A future Kulisch profile adds typed
state, conversion, and capability entries without widening shared commit types.

For the V1 512-bit datapath, geometry derives to 16 FP32 values per normalized
tile. FP16/BF16 input can generate two such tiles per port per cycle. The
default FP32 backend therefore contains four 16-lane ALU arrays (64 scalar
ALUs). These values are derived, not configurable parameters.

## Concurrent operations and storage resources

```systemverilog
// Prepared, active, complete, or releasing contexts not yet freed.
parameter int unsigned PRISM_OPERATION_CONTEXT_SLOTS = 8;

// Collective operations allowed to make progress concurrently.
parameter int unsigned PRISM_MAX_ACTIVE_OPERATIONS = 8;

// Active or OUTPUT_PENDING global ranges shared by all operations.
parameter int unsigned PRISM_ACCUMULATOR_RANGE_SLOTS = 16;

// Maximum admitted receive window, in chunks per direct stream.
parameter int unsigned PRISM_OPERATION_WINDOW_CHUNKS = 8;

// Two maximum frames per non-backpressurable physical RX port.
parameter int unsigned PRISM_INGRESS_STAGING_BEATS = 48;

// Closed local packets retained per physical ingress.
parameter int unsigned PRISM_PACKET_STORE_SLOTS_PER_PORT = 8;

// Full-frame backing storage for the per-port packet-store slots.
parameter int unsigned PRISM_PACKET_STORE_BEATS_PER_PORT = 192;

// Four maximum packets in every row-parallel source/egress VOQ cell.
parameter int unsigned PRISM_VOQ_DEPTH_BEATS = 96;

// Final elastic TX stability stage, in beats per physical egress.
parameter int unsigned PRISM_EGRESS_BUFFER_BEATS = 4;

// Direct reliable transfers that may await acknowledgment concurrently.
parameter int unsigned PRISM_REPLAY_SLOTS = 16;

// Full-frame backing capacity shared by the default replay slots.
parameter int unsigned PRISM_REPLAY_BUFFER_BEATS = 384;

// Maximum complete fragmented CONTROL transaction.
parameter int unsigned PRISM_MGMT_REASSEMBLY_BYTES = 8192;
```

Eight active operations share sixteen live ranges and the arithmetic backends.
These initial limits must be revalidated after OpenNIC synthesis; discovery
reports both compiled maxima and current availability.

The VOQ matrix is physically or logically write-parallel by source row. All two
ingress rows and internal injection rows may enqueue in one cycle, even toward
the same egress, because they target distinct `VOQ[source][egress]` cells.

## Scheduling, forwarding, and reliability defaults

```systemverilog
// Forward non-local traffic; strict ownership remains runtime-selectable.
parameter prism_forward_policy_e PRISM_FORWARD_POLICY_DEFAULT = PM_TRANSPARENT;

// Packet round robin with age escalation for mandatory traffic.
parameter prism_sched_policy_e PRISM_SCHED_POLICY = SCHED_RR_AGE;

// Eligible packet starts allowed ahead of a waiting result/ACK/control packet.
parameter int unsigned PRISM_SCHED_MANDATORY_MAX_WAIT_PKTS = 8;

// Start only closed packets in V1 to simplify the gap-free proof.
parameter bit PRISM_CUT_THROUGH_ENABLE = 1'b0;

// Direct-transfer retry limit unless the operation overrides it.
parameter int unsigned PRISM_RETRY_LIMIT_DEFAULT = 3;

// Direct-peer acknowledgment deadline, in microseconds.
parameter int unsigned PRISM_ACK_TIMEOUT_US_DEFAULT = 100;

// Default direct-stream selective-acknowledgment bitmap/window, in chunks.
parameter int unsigned PRISM_SELECTIVE_ACK_WINDOW = 8;

// Maximum CONTROL fragments in one atomic transaction.
parameter int unsigned PRISM_MGMT_MAX_FRAGMENTS = 8;

// Width of each saturating statistics counter.
parameter int unsigned PRISM_STATS_COUNTER_W = 64;
```

Scheduling is packet-granular and cannot preempt an accepted packet before
`tlast`. Retry/window values may be overridden per operation within compiled
limits.

## Required elaboration checks

`prism_pkg.sv` and `prism_switch_top` must reject builds with a non-byte AXI
width, fixed headers wider than the first-beat parser, insufficient route-mask
bits, queues smaller than one promised packet, unsupported advertised tuples,
windows larger than tracker/replay capacity, non-power-of-two bank selections,
or missing packetizer/finalizer support for an enabled output format. Capability
and resource responses are generated from the same checked constants.

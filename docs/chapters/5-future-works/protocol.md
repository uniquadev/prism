# 5.1 Protocol

The following points are intentionally outside the first MiniSharp thesis protocol: 

- allreduce semantics;
- broadcast semantics;
- reduce-scatter semantics;
- non-contiguous egress destination sets;
- bitmap or table-based result routing;
- generic configuration read/write messages;
- setup acknowledgments or status responses;
- production security for in-band setup;
- jumbo-frame protocol profile;
- sideband control-plane mapping.

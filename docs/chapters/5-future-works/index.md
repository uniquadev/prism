# 5. Future work

The thesis identifies the following extensions beyond the current SINGLE
prototype. Physical validation and multi-switch integration come first;
additional collectives, numerical formats, and application-level studies build
on those capabilities.

| Area | Scope |
| --- | --- |
| [Hardware](hardware.md) | Tests and measurements on the U280, and the multi-switch datapath. |
| [Protocol](protocol.md) | Compressed Kulisch NumberGroups and RoCE interoperability. |
| [Numerical formats](numerics.md) | Additional collectives, operators, accumulation policies, and shared-scale formats. |
| [Applications](applications.md) | Effects of exact reductions on convergence and time to solution in AI and HPC. |

These pages distinguish current evidence from the implementation and evaluation
still required. The U280 board build meets timing and its resources are
measured; on-board performance and power remain to be measured.
